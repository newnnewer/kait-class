# KAIT-CLASS — 소스 구성

파일마다 하는 일을 적은 개발용 문서입니다. 설치 방법은 저장소 첫 화면의 [README](../README.md) 를 보세요.

`install.sh` 는 이 폴더(`docs/`)와 `README.md` · `LICENSE*` · `CHANGELOG.md` · `install.sh` · `get.sh` ·
`judge-worker.service` 를 웹 폴더에 복사하지 않습니다.

## 손으로 설치할 때 (개발용)

`install.sh` 를 쓰지 않고 PHP 개발 서버 등에 올려 볼 때:

1. `cp config.sample.php config.php`
2. `config.php` 의 `db_path` 가 가리키는 폴더를 만들고 웹 서버 사용자가 쓸 수 있게 한다
   ```bash
   sudo mkdir -p ../kait-class-data
   sudo chown www-data:www-data ../kait-class-data
   ```
3. 브라우저로 접속하면 DB 와 관리자 계정(`admin`)이 만들어진다
4. 관리자 비밀번호를 정한다
   ```bash
   sudo -u www-data php reset-admin.php
   ```
