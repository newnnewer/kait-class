# KAIT-CLASS

**컴퓨팅 사고력이 자라는 특별한 프로그래밍 수업**

학생이 코드를 **직접 입력**해 문제를 푸는 **공교육의 정보수업**을 위한 도구입니다.

학생들이 AI 가 만든 코드를 붙여넣어 문제를 푸는 일이 늘었습니다.
KAIT-CLASS 는 AI 사용 자체를 막으려는 것이 아니라, **코드를 직접 손으로 입력하여 자신의 생각을 프로그래밍 언어로 잘 표현할 수 있도록** 하기 위해 만들었습니다.


---


## 주요 기능

- **문제 풀이와 자동 채점** — Python, C 등 여러 언어를 지원합니다.
- **수업과 평가** — 반별로 공개하고 기간을 정합니다.
  - 수업: 붙여넣기 제한을 설정할 수 있습니다.
  - 평가: 붙여넣기는 언제나 막고, **정해진 횟수만큼 통과**해야 완료입니다.
    한 번 통과하면 입력란과 되돌리기 기록이 비워져 **코드를 다시 입력해야** 합니다.
- **진행 현황** — 학생별 완료 여부, 제출 기록, 입력 통계, 현황표 내려받기
- **회원** — CSV 로 반 학생 일괄 등록, 회원가입(승인제 적용 가능)
- **문제 관리** — 마크다운 문제 설명, 테스트케이스, 번호 일괄 수정, FPS XML 가져오기·내보내기
- **운영** — 공지, 사이트 이름·로고, 채점 대기열 확인과 재채점, 언어 관리
- **간단한 설치** — 단 한 줄의 명령어로 설치할 수 있으며, 도메인이 있다면 https(SSL)까지 붙입니다.

## 필요한 것

| | |
|---|---|
| CPU | **인텔·AMD (x86_64)** — ARM 기계(라즈베리파이, 애플 실리콘 등)에서는 채점 엔진이 동작하지 않습니다. |
| 메모리 | 2GB 에서도 동작합니다. **100명 이상이 동시에 참가하는 대회를 열려면 4GB 이상 권장** |
| 디스크 | 여유 20GB 이상 |
| OS | **Ubuntu 24.04 LTS** — 새로 설치한 깨끗한 상태를 권합니다. |

### 어떤 우분투를 설치할까요?

-  무선 환경에서 운영할 때 설치에 용이한 **우분투 데스크톱**을 적극 추천합니다.
-  설치 화면에서는
`Install third-party software for graphics and Wi-Fi hardware` 에 **체크**하고,
설치 뒤 뜨는 **소프트웨어 업데이트 창은 누르지 마세요** (설치 스크립트가 필요한 기능을 설치합니다).

## 설치

### 방법 1. 한 줄 설치

터미널을 열고 다음 명령어를 실행합니다.

```bash
wget -qO- https://raw.githubusercontent.com/newnnewer/kait-class/main/get.sh | sudo bash
```

명령어를 실행하면 최신 버전을 홈 폴더(`~/kait-class-버전`)에 내려받아 설치를 시작합니다.

### 방법 2. zip 을 받아서

1. [Releases](https://github.com/newnnewer/kait-class/releases) 에서 최신 버전의 **Source code (zip)** 을 받습니다.
2. 파일 앱에서 zip 을 **오른쪽 클릭 → 압축 풀기**
3. 풀린 폴더 안 빈 곳을 **오른쪽 클릭 → 터미널에서 열기**
4. 입력
   ```bash
   sudo bash install.sh
   ```

> 클라우드 서버라면 zip 을 **홈 폴더**에 올려서 푸세요. `/tmp` 는 중간 재부팅 때 지워질 수 있습니다.

### 재부팅 후 한 번 더

설치는 두 번에 나뉩니다. 설치 도중에 채점 엔진 설정을 위해 **재부팅**을 묻습니다.

재부팅한 뒤 터미널을 열면 노란 안내가 나옵니다. 안내대로 **같은 명령을 한 번 더** 입력하면 나머지가 설치됩니다.

```bash
cd ~/kait-class-버전      # 안내에 나온 폴더
sudo bash install.sh
```

처음 설치는 인터넷 속도에 따라 10~30분 걸립니다. 끝나면 접속 주소가 나옵니다.

### 처음 로그인

관리자 아이디는 `admin` 입니다. **설치가 끝나면 다음 명령어를 실행하여 관리자 비밀번호를 설정하세요.**

```bash
cd /var/www/html && sudo -u www-data php reset-admin.php
```

그 뒤 브라우저로 접속해 로그인하고, **운영 > 설정** 에서 사이트 이름과 로고를 바꿀 수 있습니다.

## 도메인과 https

도메인이 있다면 무료 인증서(Let's Encrypt)를 받아 https 로 운영할 수 있습니다.
**도메인이 없으면 이 절은 건너뛰세요.** `http://IP주소` 로도 동작합니다.

1. **도메인 연결** — 도메인 관리 화면에서 A 레코드를 이 서버의 **공인 IP** 로 설정합니다.
   (공유기 내부에 설치했다면 `192.168…` 이 아니라 공유기 외부 주소)
2. **80·443 번 열기** — 공유기라면 포트포워딩, 클라우드라면 콘솔 방화벽
3. **실행** (설치한 폴더에서)
   ```bash
   sudo bash install.sh --domain class.example.kr --email 나@example.com
   ```

- 메일은 인증서가 곧 만료될 때 Let's Encrypt 가 알려 주는 데만 쓰입니다.
- 인증서는 우분투가 **자동으로 갱신**합니다.
- 도메인을 기억하므로, 다음 업데이트부터는 옵션 없이 실행하면 됩니다.
- 인증서를 받지 못해도 설치는 멈추지 않습니다. 사이트는 http 로 동작하고, 끝 화면에 원인이 나옵니다.
- 공유기 안에서는 `http://내부IP` 로도 계속 접속할 수 있습니다.

그 밖의 옵션은 `sudo bash install.sh --help` 로 볼 수 있습니다.

## 업데이트

새 버전을 **새 폴더에 받아서 같은 명령**을 실행합니다. 한 줄 설치를 다시 실행해도 됩니다.

```bash
sudo bash install.sh
```

- 설정, 올린 이미지, DB(학생·제출 기록)는 **그대로** 남습니다.
- 기존에 진행되었던 단계들은 건너뛰므로 몇 분이면 끝납니다.
- 바뀐 화면이 안 보이면 브라우저에서 `Ctrl+F5`

바뀐 내용은 [CHANGELOG.md](CHANGELOG.md) 에 있습니다.

## 쓰실 때 알아 둘 것

- **노트북을 서버로 쓸 때** — 설치 스크립트가 절전을 막아 둡니다. 덮개를 닫아도 절전모드로 진입하지 않습니다.
- **백업** — 수행평가 기록이 쌓이면 DB 파일(`/var/www/kait-class-data/kait-class.db`)을 주기적으로 다른 곳에 복사해 두세요.
- 관리자 비밀번호를 잊었다면 위의 `reset-admin.php` 를 다시 실행하면 됩니다.

## 문제가 생겼을 때

설치가 멈추면 화면에 **멈춘 단계, 기록 마지막 부분, 다시 실행할 명령**이 나옵니다.
원인을 고친 뒤 같은 명령을 다시 실행하면 이어서 진행합니다.

| 멈춘 곳 | 흔한 원인 |
|---|---|
| 1 설치 환경 확인 | 학교·기관 와이파이의 로그인·보안 장비, ARM 기계, 소스를 `/tmp` 에 풂 |
| 5 Docker | snap 으로 설치한 docker → `sudo snap remove docker` |
| 6 방화벽 | SSH 포트를 찾지 못함 → `sudo ufw allow <포트>/tcp` 후 다시 |
| 7 채점 엔진 | `toomanyrequests` → Docker Hub 받기 횟수 제한. 시간을 두고 다시 |
| 9 웹 서버 | apache2 가 실행 중 → `sudo systemctl disable --now apache2` |

전체 기록:

```bash
sudo less /var/log/kait-class-install.log
```

## 이용 조건

KAIT-CLASS 는 **[PolyForm Noncommercial 1.0.0](LICENSE)** 으로 소스를 공개합니다.
소스는 공개되어 있지만 상업적 이용을 금지하므로 오픈소스 소프트웨어는 아닙니다.

| 할 수 있는 것 | 할 수 없는 것 |

| 수정, 수정본 배포 (표기 유지) | 판매, 설치·호스팅·운영 대행, 기업의 영리 이용 |

- 화면 꼬리말의 **저작권 표기를 지울 수 없습니다.**
- 상업적 이용을 허용하지 않습니다.
