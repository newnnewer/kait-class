# KAIT-PLAY — 설치 · 운영 안내

KAIT-PLAY 는 **KAIT-CLASS 와 함께 설치**됩니다. 주소는 언제나 KAIT-CLASS 주소 뒤의 **`/play/`** 입니다.

| | 주소 |
|---|---|
| 학생 | `http(s)://주소/play/` |
| 교사 화면 | `http(s)://주소/play/teacher` |

- 게임 서버는 **Docker 컨테이너 하나**(`kait-play`)이고, 설치 위치는 `/opt/kait-play` 입니다.
- 서버 안의 `127.0.0.1:3100` 에서만 열립니다. 바깥에서는 nginx 의 `/play/` 를 거쳐서만 들어옵니다.
  KAIT-CLASS 가 https 로 운영 중이면 KAIT-PLAY 도 그대로 https 입니다.
- nginx 연결은 `/etc/nginx/kait-class.d/kait-play.conf` 한 파일입니다 (KAIT-CLASS 가 비워 둔 '추가 프로그램 자리').

---

## 0. 한 번만: 스왑 추가 (메모리 2GB 서버, 권장)

메모리가 2GB 이고 스왑이 없으면, 순간적으로 메모리가 모자랄 때 프로그램이 강제로 꺼질 수 있습니다. 2GB 를 추가해 둡니다. 기존 서비스에는 영향이 없습니다.

```bash
sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile
sudo mkswap /swapfile && sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
free -h      # Swap 줄에 2.0Gi 가 보이면 완료
```

## 1. 설치 · 업데이트

### KAIT-CLASS 와 함께 (보통)

KAIT-CLASS 의 `sudo bash install.sh` 가 14단계에서 KAIT-PLAY 를 설치합니다. 따로 할 일이 없습니다.
(`--no-play` 를 붙이면 빼고 설치합니다.)

### KAIT-PLAY 만

KAIT-CLASS 는 그대로 두고 KAIT-PLAY 만 설치하거나 새 버전으로 바꿀 때 (KAIT-CLASS 1.1 이하가 설치된 서버에 더할 때도):

```bash
cd ~/kait-class-버전          # 새 소스를 푼 폴더
sudo bash play/install.sh
```

- `/opt/kait-play/.env`(설정)와 `/opt/kait-play/data/`(기록 · 문제 은행 · 바꾼 교사 비밀번호)는 그대로 유지됩니다.
- 예전 이름(코딩 대항전: `/opt/coding-game`, 컨테이너 `coding-battle`, 주소 `/game/`)으로 설치된 것이 있으면
  **자료와 설정을 옮기고** 예전 컨테이너 · nginx 연결을 정리합니다. 예전 폴더는 `/opt/coding-game.old-날짜` 로 남겨 둡니다.
  예전 주소 `/game/…` 로 들어오면 `/play/…` 로 넘겨 줍니다.
- 처음에는 Docker 이미지를 만드느라 1~3분 걸립니다.

> 다시 설치하면 게임 서버가 재시작되어 **진행 중인 게임은 사라집니다.** 수업 중에는 하지 마세요.

### 개발용: PC 에서 연습 서버로 올리기

`play\deploy\upload-test-server.bat` 을 두 번 누르면 `play` 폴더를 묶어 서버로 보내고 `play/install.sh` 를 실행합니다.
서버 주소는 같은 폴더의 `server.local.bat` 에 적어 둡니다 (GitHub 에 올리지 않는 파일):

```bat
set SERVER=root@서버IP
set SSH_PORT=22
```

> **교사 화면 비밀번호** (아이디 없이 비밀번호 하나, **KAIT-CLASS 관리자 비밀번호와 따로**)
> - **처음 비밀번호**: 설치할 때 무작위로 만들어 설치 끝 화면에 보여 줍니다. 다시 보기: `sudo grep ADMIN_PASSWORD /opt/kait-play/.env`
> - **바꾸기**: 교사 화면 위쪽 **비밀번호 바꾸기**. 바꾼 비밀번호는 암호화해서 `data/game.db` 에 저장되고, 그때부터 `.env` 의 처음 비밀번호는 쓰이지 않아요. 다른 컴퓨터의 교사 화면은 로그아웃돼요.
> - **잊었을 때**: `sudo docker exec kait-play node scripts/admin-password.js` → 새 비밀번호를 만들어 보여 줘요(재시작 필요 없음). 직접 정하려면 끝에 비밀번호를 붙이세요. **실행하면 지금 비밀번호가 바뀌니, 잊었을 때만** 쓰세요.
> - http 로 운영하면 비밀번호가 암호화되지 않고 전송되므로, 다른 곳에 쓰지 않는 비밀번호만 쓰세요.

## 2. 확인하기

1. 학교 PC 브라우저로 **http://주소/play/** 을 엽니다.
2. 닉네임을 뽑고, 캐릭터와 색을 고른 뒤 **입장하기**를 누릅니다.
3. 게임 화면 오른쪽 위에서 연결 방식을 확인합니다.

   | 표시 | 뜻 |
   |---|---|
   | 🟢 실시간 연결 (WebSocket) | 가장 좋은 상태 |
   | 🟠 대체 연결 (폴링) | 학교망이 WebSocket을 막고 있음. 게임은 되지만 조금 느림 → 알려 주세요 |
   | 🔴 연결 끊김 | 서버에 닿지 않음 |

4. 두 번째 PC(또는 다른 브라우저)로 들어가서, 서로의 캐릭터가 움직이는 모습이 보이는지 확인합니다.
5. 혼자 시험할 때는 서버에서 **가상 학생**을 넣을 수 있습니다. 먼저 브라우저로 방을 만들어 대기실에서 기다린 뒤:

   ```bash
   cd /opt/kait-play && docker exec kait-play node scripts/bots.js 3
   # 가상 학생 3명이 '모집 중'인 방의 빈자리에 들어와요 (방이 없으면 생길 때까지 기다려요)
   # 방장이 시작하면 함께 움직이고 블록을 점유·제출해요. 보스 옆이면 잡아 보지만 답을 몰라 늘 틀려요
   # Ctrl + C 로 끝내기 (끝내고 1분 뒤 방에서 빠짐)
   ```

### 수업방 (5단계)

1. 교사: **http://주소/play/teacher** → 비밀번호로 로그인 → **새 수업방** → 숫자 4자리 **방 코드**가 생겨요.
2. 학생: 게임 주소로 들어가 캐릭터를 고른 뒤, 로비 맨 위 **수업방에 들어가기** 칸에 코드 입력 → **팀 선택**.
3. 교사 화면에서 설정(태그·팀 수 2~8·시간·보스·페널티·블록 수)을 고르고, 팀을 옮기거나(각 학생 옆 팀 선택) **팀 미선택 학생 자동 배정**을 누른 뒤 **게임 시작**.
4. 게임 중: **일시정지**(모든 팀의 입력과 시간이 멈춤) · **게임 종료**(두 번 누름) · **강퇴**(두 번 누름, 같은 브라우저로는 그 수업에 다시 못 들어옴). 늦게 온 학생도 팀을 고르면 바로 참여해요.
5. 순위: 판을 먼저 완성한 팀부터 → 시간이 끝나거나 종료하면 남은 팀은 해결률 순. 결과는 교사·학생 화면에 뜨고 **지난 기록**(교사 화면 위쪽 탭)에 저장돼요.
   - **팀 선택 잠그기 · 무작위로 섞기 (v0.12.0)**: 팀 현황 위쪽 버튼. 잠그면 학생은 팀을 고르거나 바꿀 수 없고(선생님은 옮길 수 있음), 섞기는 팀 미선택 학생까지 모두 무작위로 고르게 나눠요 (봇은 제자리, 게임 전에만).
   - **전광판 순위 변동 그래프 (v0.12.0)**: 전광판 위쪽 '📈 순위 그래프로 보기' 버튼이나 **B** 키로 판 모양 ↔ 순위 그래프를 바꿔요. 10초마다 팀 순위를 꺾은선으로 그리고, 오른쪽에 지금 순위 · 해결률 (그 브라우저에 기억).
6. 끝나면 같은 코드·같은 팀으로 **한 판 더** 할 수 있어요. 수업이 끝나면 **수업 끝내기**(두 번 누름). 3시간 동안 쓰지 않으면 자동으로 닫혀요.

- 모든 팀이 같은 판(같은 배치·같은 문제 순서)을 받아요. 보스는 "게임 시작부터 (보스 등장 간격)마다" 모든 팀에 같은 문제로 나와요. 그때 이전 보스가 남아 있는 팀은 한 번 건너뛰어요.
- 수업방에는 방치 자동 종료가 없어요.

### 방해 아이템 · 전광판 (5-2단계)

- 보스를 잡으면 (v0.12.0): 우리 팀 도움 57.5% (폭탄 · 가로 레이저 · 세로 레이저 · 자동완성 · 쉬운 길) · **방해 20%** · 페널티 15% · **방패 7.5%**.
- **대상 고르기 (v0.12.0)**: 방해 아이템을 Ctrl+Shift+번호로 쓰면 "몇 팀을 공격할까요?" 창이 떠요. **숫자 키로 팀 번호**를 누르면 그 팀을 공격하고, **Enter** · 같은 단축키를 한 번 더 · **3초 동안 안 고르면** 바로 위 순위 팀(그 순간 해결률 기준, 1등 팀이 쏘면 2등 팀)를 공격해요. **Esc** 는 취소(아이템은 그대로). 우리 팀 · 이미 판을 끝낸 팀은 고를 수 없고, 공격할 팀이 없으면 쓸 수 없고 아이템은 덱에 남아요.
- 아이템을 쓰거나 받을 때 뜨는 큰 알림은, **입력 중 · 보스 공략 중이면 판 위나 아래 끝에 작고 반투명하게** 떠요 (말풍선과 먼 쪽, v0.7.1).
- **공격은 2초 뒤에 들어가요 (v0.7.0)**: 대상 팀 화면에 "⚠ N팀의 OO 공격!" 경고와 2초 막대가 뜨고, 그 안에 **방패를 가진 팀원이 Ctrl+Shift+9** 를 누르면 막아요. 아무도 누르지 않으면 맞아요 (자동으로 막지 않음). 막으면 공격한 팀에도 "방패로 막았어요"가 떠요.
  | 방해 | 맞은 팀 |
  |---|---|
  | 얼음 | 8초 동안 전원 입력 금지 |
  | 먹구름 | 8초 동안 판과 말풍선의 코드가 가려짐 (입력은 됨) |
  | 되살리기 | 해결한 칸 6개가 다시 미해결로 |
  | 뒤섞기 | 보스 공략 중인 사람을 뺀 모든 팀원이 무작위의 같은 한 칸으로 (치던 블록은 점유가 풀림) |
  | 방향 반전 | 15초 동안 방향키가 반대로 (v0.12.0) |
- **방패**: 잡은 사람의 덱 옆 방패 칸에 들어가요 (한 사람 최대 2개). 공격이 들어올 때 Ctrl+Shift+9 로 직접 써요. 학생 화면 위쪽 "팀 방패 ×N"은 팀 전체 방패 수.
- 교사 화면 아래 **방해 아이템** 스위치: 게임 중에도 바로 켜고 끔. 끄면 협동방과 같은 아이템만 나와요.
- 봇도 방해를 똑같이 맞아요 (먹구름 동안은 봇도 잠깐 멈춤). 봇은 보스를 잡지 않으니 공격은 하지 않아요.
- 결과와 지난 기록에 팀마다 **공격 · 맞음 · 막음** 횟수가 남아요.
- **전광판**: 교사 화면 위쪽 **전광판 열기** → 새 창이 열려요. 프로젝터 화면으로 옮긴 뒤 **F11**(전체 화면). 1920×1080 기준이고 창 크기에 맞춰 늘고 줄어요. 교사가 로그인한 브라우저에서만 열려요.
  - 게임 전: 접속 주소와 방 코드를 크게, 팀별 들어온 사람 (한 판이 끝난 뒤에는 지난 판 결과도)
  - 게임 중: 남은 시간 · 방해 ON/OFF · 공격 알림 띠 · 팀별 카드(순위 · 해결률 · 작은 판 · 얼음/먹구름/CLEAR · 팀원 · 효과와 방패) · 전장 소식
  - 일시정지하면 전광판에도 "일시정지"가 떠요.
- **학생 방 만들기 허용** 스위치(교사 화면)를 끄면 학생이 대전방 · 협동방을 새로 만들 수 없어요. 서버를 다시 켜도 유지돼요.
- **봇으로 인원 맞추기**: 교사 화면의 **봇으로 인원 맞추기**를 누르면 **모든 팀**(사람이 없는 팀도, v0.7.6)를 가장 큰 팀 인원까지 봇으로 채워요. 팀마다 **+ 봇 넣기**, 봇 옆 **빼기**, **봇 모두 빼기**도 있어요. 봇은 서버 안에서 일반 블록만 풀고(가끔 틀림) 보스는 잡지 않아요. 속도는 설정의 **봇 속도**(느림 20초 · 보통 12초 · 빠름 7초에 한 블록). 학생 화면·결과·기록에 "(봇)"으로 보여요. 봇은 수업을 끝낼 때까지 팀에 남아요.
- 혼자 시험할 때: 교사 화면에서 수업방을 만든 뒤 서버에서 `docker exec kait-play node scripts/bots.js 12 --class 코드` → 가상 학생 12명이 1팀부터 차례로 들어가요.

- **시작 카운트다운 (v0.7.6)**: 학생 방 · 수업방 모두 '게임 시작'을 누르면 게임 화면으로 바뀌고 판이 보인 채 **5초 카운트다운**(준비! 5 → … → 시작!) 뒤에 움직일 수 있어요. 그동안 제한 시간 · 보스는 흐르지 않고, 교사 '일시정지'는 카운트다운이 끝난 뒤에 눌러요. 전광판 시계에는 '준비 5'.

### 흐름 (학생 방 — 협동방 · 대전방, v0.13.0)

입장(닉네임·캐릭터) → **로비**(위: 수업방 코드 · 아래 두 칸: **대전방** | **협동방**) → 칸마다 **＋ 방 만들기** 또는 모집 중인 방 **들어가기** → **대기실**(모두 **준비**) → 방장이 **게임 시작**(또는 15초 뒤 자동 시작) → 게임 → **결과** → 같은 방 대기실로 (바로 한 판 더)

- 이름은 임시: **수업방**(교사가 여는 게임, 예전 '수업 게임') · **대전방**(학생이 여는 팀 대전) · **협동방**(학생이 여는 협동, 예전 '학생 방').
- **협동방**: 모두가 판 하나를 같이 채워요 (예전 학생 방과 같음). 다른 팀을 공격하는 아이템과 방패는 나오지 않아요.
- **대전방**: **2~4팀 × 팀마다 1~8명**(1:1 도 됨, 한 방 최대 32명). 수업방처럼 팀마다 같은 판 · 같은 문제 순서, 보스는 모든 팀에 같이 나오고(3명 이상 팀은 집결 보스), **방해 아이템은 늘 나와요**(끄는 스위치 없음). 순위: 판을 먼저 완성한 순 → 시간이 끝나면 해결률 순 → **팀원(사람)이 모두 나간 팀은 기권**(맨 아래). 결과 화면에 팀 순위와 순위 변동 그래프.
  - 들어오면 **사람이 적은 팀**에 앉아요. 다른 팀의 빈자리를 눌러 스스로 옮겨요. 팀을 옮겨도 준비는 그대로.
  - 시작하려면 사람이나 봇이 있는 팀이 **2팀 이상**이어야 해요. 인원이 다르면 경고만 하고(막지 않음) 방장에게 **🤖 봇으로 인원 맞추기** 버튼이 나와요 (모든 팀을 가장 큰 팀 인원까지).
  - 블록 수 자동 = 가장 큰 팀 인원 × 24 (최대 96).
- **준비 (v0.13.0, 협동방 · 대전방 모두)**: 방장 말고 모두 **준비**(Ctrl + Enter, 다시 누르면 풀림)해야 방장이 시작할 수 있어요. 봇은 늘 준비. 다른 사람이 한 명 이상 있고 모두 준비되면 **15초 뒤 자동 시작**(방장은 그 전에 바로 시작 가능). 누가 새로 들어오거나 준비를 풀면 멈췄다가, 다시 모두 준비되면 처음부터 세요. 한 판이 끝나면 준비는 모두 풀려요.
- **방장**: 시작 · 봇 넣고 빼기 · (대전방) 학생을 다른 팀으로 옮기기(사람 카드의 팀 고르기) · **내보내기**(두 번 눌러야, 내보낸 학생은 같은 방에 다시 못 들어옴). 방장이 나가거나 **연결이 10초 넘게 끊기면** 다음 사람(연결된 사람 먼저)이 방장.
- 방 만들기에서 정하는 것: 문제 태그(여러 개), 협동방은 최대 인원(2~16) · 대전방은 팀 수(2~4) × 팀 인원(1~8), 제한 시간(1~30분 직접 입력, 기본 5분), 블록 수(자동 / 직접 24~144칸), 봇 속도. **블록 점유 20초 · 보스 등장 간격 15초 · 잔류 8초 · 풀이 30초 · 페널티 있음은 학생 방에서 고정**(v0.13.0, 수업방은 교사가 고름). 방을 연 뒤에는 바꿀 수 없어요.
- 방 이름은 방장 닉네임으로 자동. 같은 브라우저는 1분에 방 1개까지, 서버 전체 방은 최대 60개. 10분 동안 시작하지 않으면 방이 닫혀요. 사람이 모두 나가면 방이 없어져요.
- **한마디 (v0.7.3)**: 대기실과 팀 선택 화면(수업방)에서 **정해 둔 문구**로 방 전체에 이야기해요. 묶음(응답 · 인사 · 준비 · 작전 · 끝난 뒤)을 누르거나 **← →** 로 바꾸고, 문구를 누르거나 **숫자 키 1~9** 로 보내요. 한 사람 **2초에 한 번**. 말한 사람 카드 위에 3초 동안 말풍선, 아래에 최근 대화. 문구 목록은 `public/js/shared/chat.js`.
- **봇 (v0.6.4)**: 방장은 빈자리의 **+ 봇 넣기**로 봇을 넣고(대전방은 팀마다), 봇 카드의 **빼기**로 빼요. 봇도 인원에 들어가요. 봇은 일반 블록만 풀고 보스는 잡지 않아요. 봇의 움직임은 방치 판정에 들어가지 않고, 사람이 모두 나가면 봇이 있어도 방이 닫혀요.
- 진행 중인 방에는 들어갈 수 없어요. 새로고침하면 있던 곳(대기실·게임)으로 돌아와요 (연결이 끊기고 1분 안).
- 게임 중 1분 동안 아무도 입력하지 않으면 15초 경고, 그대로 두면 끝나요 (대전방은 그 팀만 끝나고, 모든 팀이 그렇게 끝나면 방이 닫혀요).
- 게임 중 '나가기'(또는 Alt + Q)는 두 번 눌러야 나가져요 (실수 방지).

- **보스**: 보스가 끝나고 (방 설정의 간격) 뒤 미해결 블록 하나가 보라색 보스로 바뀌어요. (잔류 시간) 안에 아무도 안 잡으면 달아나요. 공략은 (풀이 시간). 기본값은 15초 · 8초 · 30초.
- 보스를 맞히면 그 칸이 해결되고 **왕관과 해결한 사람 이름**이 남아요. 나온 아이템은 **잡은 사람의 개인 덱**(화면 아래 5칸)에 들어가고, 원할 때 **Ctrl+Shift+1~5** 로 써요 (v0.7.0). 덱이 가득 차 있으면 새 아이템은 사라져요. 게임이 끝나면 남은 아이템도 사라져요.
  - 좋은 아이템(90%): 폭탄(**내가 서 있는 칸** 둘레 8칸 모두, 점유 중인 칸도) · 가로 레이저(내 가로줄 남은 칸 모두) · 세로 레이저(내 세로줄 남은 칸 모두) · 자동완성(쓰는 순간부터 10초) · 쉬운 길(내 둘레 8칸을 짧은 코드로, v0.7.1) — 레이더는 v0.7.1 에서 뺐어요
  - 페널티(10%): 덱에 들어가지 않고 **바로** 발동 — 자폭(5초 얼음) · 역풍(해결 칸 4개 되살아남) · 혼란(15초 방향 반전, v0.12.0)
- **집결 보스 (v0.7.0)**: 접속 중인 사람이 3명 이상인 팀에서 보스 차례 4번에 1번 나와요 (봇은 세지 않음). 아무 줄의 **왼쪽에서 두 번째 칸** 또는 **오른쪽에서 두 번째 칸**에 주황색으로 나타나고, **8초 안에 팀원 모두가 그 바로 왼쪽 칸에서 Delete, 오른쪽 칸에서 Backspace 로 잡으면** 성공 (v0.12.0) — ↑↓로 그 줄에 가서 Home/End 를 누르면 보스 바로 옆에 서요. 잡은 사람은 자리를 떠나도 되고, 서 있기만 해서는 안 잡혀요. 성공하면 팀원 모두의 덱에 도움 아이템이 1개씩 들어가고 그 칸이 해결돼요(왕관 '모두'). 수업방에서는 모든 팀이 같은 차례 · 같은 자리이고, 3명 미만인 팀에는 그 차례에 보통 보스가 나와요.
  - 폭탄·레이저가 누가 치고 있던 칸을 해결하면 그 사람의 말풍선이 닫히고 "폭탄으로 해결됐어요!"가 떠요 (개인 기록에는 안 셈)
- 틀리거나 시간이 지나면 보스는 일반 블록으로 돌아가요. 정답은 알려 주지 않아요.
- 남이 점유한 칸은 그 사람 색으로 칠해지고 "OO 점유"라고 보여요.
- 붙여넣기·Tab·몇몇 브라우저 단축키(Ctrl+F, F5 등)는 막혀 있어요. 한글이 입력되면 지우고 안내가 떠요.
- 판을 모두 해결하면 성공, 제한 시간이 지나면 시간 초과로 결과 화면이 나와요.

## 문제 은행 (6단계)

- 교사 화면 위쪽 **문제 은행** 탭: 일반/보스 · 태그로 거르기 · 검색. 문제를 누르면 고치기(코드 · 태그, 보스는 제목 · 입력 · 정답)와 **지우기**(두 번 누름).
- 고치는 창 아래 **채점 시험**: 학생이 칠 법한 답을 넣으면 게임과 같은 규칙으로 정답/오답을 알려 줘요. 보스 정답을 새로 넣었으면 꼭 한 번 해 보세요 (정답이 틀리면 그 보스는 아무도 못 잡아요).
- **붙여넣기로 추가**: 문제 은행 파일과 같은 형식으로 붙여넣고 **미리보기** → 새 문제 · 태그만 더함 · 이미 있음 · 오류를 확인 → **추가하기**. 이미 있는 문제(띄어쓰기 무시)는 새로 넣지 않고 태그만 더해요. 보스는 코드가 같아도 제목이 다르면 다른 문제로 봐요.
- **내려받기 (bank.txt)**: 문제 은행 전체를 파일로 (백업 · 집 서버로 옮기기).
- 고친 문제는 **다음에 시작하는 게임부터** 나와요. 코드와 정답에는 한글을 쓸 수 없어요.
- 문제는 `data/game.db`에 저장돼요. `problems/bank.txt`는 **처음 켤 때 한 번만** 가져오므로, 그 뒤로 bank.txt를 고쳐 올려도 반영되지 않아요 → 화면의 붙여넣기를 쓰세요.

## 소리 (6-2단계)

- 소리 파일 없이 브라우저가 직접 만들어요 (8비트 게임기 느낌). 교사 화면 위쪽 **소리 미리듣기**에서 모든 소리를 들어 볼 수 있어요.
- **학생 기기 효과음** (v0.12.0: 전광판과 같은 크기): 점유 · 정답 · 오답 · 보스 등장/격파 · 아이템(폭탄·레이저·방패 등) · 페널티 · 공격 받음 · 얼음 · 먹구름 · 판 완성 · 결과 · 마지막 10초 틱 · **타자음**(글자마다 톡) · **오류음**(틀린 글자를 칠 때마다 짧은 '틱', v0.12.0).
  - 내 행동과 우리 팀에 생긴 일만 소리가 나요 (팀원 각자의 정답 소리는 안 나요).
  - 학생은 게임 화면 위쪽 **배경음 켬/끔 · Ctrl+S**(배경음과 효과음)와 **타자음 켬/끔 · Ctrl+K**(타자음과 오류음)를 **따로** 켜고 끌 수 있어요 (v0.12.0, 브라우저에 기억).
  - 교사 화면 아래 **학생 효과음** 스위치를 끄면 그 수업방의 모든 학생 기기가 조용해져요 (게임 중에도 바로).
- **전광판**: 오른쪽 위 **🔈 소리 켜기**를 한 번 눌러야 소리가 나요 (브라우저 정책). 게임 중 배경음(마지막 30초는 빠르게, 일시정지 · 끝나면 멈춤) + 공격 · 방패 · CLEAR · 시작 · 끝 · 마지막 10초 효과음. 교사 화면 **전광판 배경음** 스위치로 배경음만 끌 수 있어요.
- 스피커가 없거나 음소거여도 게임은 그대로 돼요.

## 자료 백업 · 되돌리기

`data/game.db`에 문제 은행 · 게임 기록 · 교사 비밀번호 · 설정이 모두 들어 있어요.

```bash
bash /opt/kait-play/deploy/backup.sh
# → /opt/kait-play/data/backup/game-2026-09-29_2130.db (최근 30개만 남김, 게임 중에도 안전)

# 매일 새벽 3시 자동 백업 (root 에서 한 번만)
(crontab -l 2>/dev/null; echo '0 3 * * * bash /opt/kait-play/deploy/backup.sh >/dev/null 2>&1') | crontab -
```

되돌리기 (백업한 때로):
```bash
cd /opt/kait-play
docker compose down
cp data/game.db data/game.db.before-restore        # 지금 것도 한 번 보관
cp data/backup/game-2026-09-29_2130.db data/game.db
chown 1000:1000 data/game.db
docker compose up -d
```

## 부하 시험 (6-3단계)
가상 학생이 실제 학생처럼 놀면서(걸어가서 점유 → 타이핑 → 제출, 보스 · 아이템 · 방패 · 집결 보스, 대기실 한마디) 서버가 얼마나 빨리 답하는지 재요. **수업이 없는 시간에** 연습 서버에서:

```bash
cd /opt/kait-play
# 1) 학생 방만: 10개 방 × 7명 = 70명, 5분
docker exec kait-play node scripts/loadtest.js --rooms 10 --per 7 --minutes 5
# 2) 수업방 30명 (교사 역할도 자동: 수업방을 만들고, 모두 들어오면 시작, 끝나면 닫음)
docker exec kait-play node scripts/loadtest.js --teacher 교사비밀번호 --students 30 --teams 6 --minutes 5
# 3) 둘을 함께 = 100명
docker exec kait-play node scripts/loadtest.js --teacher 교사비밀번호 --students 30 --teams 6 --rooms 10 --per 7 --minutes 5
```
- 10초마다 한 줄: 접속 수 · 경기 수 · **응답 시간**(움직임을 보내고 새 위치가 돌아오기까지) · **서버 메모리** · **밀린 시간**(서버가 바빠 늦어진 시간). 끝나면 요약.
- 판단 기준(대략): 응답 보통 100ms 아래 · 느린 5% 300ms 아래 · 밀린 시간 100ms 아래면 매끄러워요. 메모리는 서버 여유(약 860MB)보다 한참 작아야 해요.
- 가상 학생은 같은 서버 안에서 돌기 때문에 실제보다 조금 더 무거운 시험이에요.
- 교사 비밀번호가 명령 기록에 남으니, 테스트용 비밀번호일 때만 `--teacher` 를 쓰세요. 아니면 `--class 코드` 로 교사 화면에서 만든 수업방에 넣고 직접 '게임 시작'.
- 가상 학생은 끝난 뒤 1분 동안 '연결 끊김'으로 남았다가 빠져요.
- 서버 상태만 볼 때: `curl -s http://127.0.0.1:3100/play/healthz` (memMB · lagMaxMs · matches 등).

### 큰 시험 (300명 넘게, v0.8.1)
수업방 여러 개 + 학생 방 여러 개를 한 번에. 먼저 아래 '많은 인원 받기'의 **최대 접속 인원**을 늘려 두세요.
게임 컨테이너는 메모리 한도가 300MB 라, 큰 시험은 도구를 **따로 된 컨테이너**에서 돌려요 (같은 컨테이너에서 돌리면 서버가 꺼질 수 있음).
```bash
cd /opt/kait-play
# 수업방 8개 × 30명 (판이 끝나면 5초 뒤 다음 판) + 학생 방 40개 × 7명 = 520명, 10분
docker run --rm -it --network host kait-play:latest node scripts/loadtest.js --url http://127.0.0.1:3100/play \
  --teacher 교사비밀번호 --classes 8 --students 240 --teams 6 --rooms 40 --per 7 --minutes 10
```
- `--classes`(수업방 수, 최대 20) · `--students`(수업방 학생 모두, 수업마다 똑같이 나눔) · `--rooms`(최대 60) · `--per` · `--round`(수업방 한 판 분, 기본 3) · `--ramp`(접속 간격 ms, 기본 20).
- 10초마다 **시험 도구 CPU**도 보여 줘요. 요약에 '도구가 바빴어요'가 나오면 응답 시간이 부풀려진 거라 인원을 나눠 돌리세요.
- '사람이 너무 많아요'로 입장 실패가 나오면 최대 접속 인원에 걸린 것.
- **연습 서버 결과 (2026-09-30)**: 520명 · 10분 — 응답 보통 1ms · 느린 1% 4ms · 서버 메모리 최대 103MB · 끊김 0.

## 많은 인원 받기 (한 번만)
한 반(30명) 정도는 기본 설정으로 충분해요. 여러 반이 동시에(수백 명) 쓰려면:

1. **게임 최대 접속 인원** (기본 300) — `.env` 를 고치고 서버를 다시 만들기 (`restart` 로는 안 바뀜):
   ```bash
   cd /opt/kait-play
   sed -i 's/^MAX_PLAYERS=.*/MAX_PLAYERS=600/' .env
   docker compose up -d
   docker exec kait-play printenv MAX_PLAYERS   # 600 이 나오면 됨
   ```
2. **nginx 연결 수** — 설치할 때 자동으로 4096 으로 맞춰요 (KAIT-CLASS 1.2 · `play/install.sh`). 확인: `grep worker_connections /etc/nginx/nginx.conf`.
   아래는 손으로 할 때의 방법이에요. 학생 한 명이 연결 2개(학생↔nginx, nginx↔게임)를 써요. 우분투 기본 `worker_connections 768` 은 수백 명에 빠듯 → 4096 으로. KAIT-CLASS 와 함께 쓰는 설정이지만 한도만 늘리는 것이고, 끊김 없이 적용돼요. 실패하면 자동으로 되돌려요:
   ```bash
   cp /etc/nginx/nginx.conf /etc/nginx/nginx.conf.bak-$(date +%F)
   sed -i 's/worker_connections 768;/worker_connections 4096;/' /etc/nginx/nginx.conf
   grep -q worker_rlimit_nofile /etc/nginx/nginx.conf || sed -i '/^worker_processes/a worker_rlimit_nofile 8192;' /etc/nginx/nginx.conf
   if nginx -t; then systemctl reload nginx && echo 적용됨; else cp /etc/nginx/nginx.conf.bak-$(date +%F) /etc/nginx/nginx.conf && echo 되돌림; fi
   grep -E "worker_(processes|rlimit_nofile|connections)" /etc/nginx/nginx.conf
   ```

## 체험(데모) 서버로 쓸 때

누구에게나 교사 비밀번호를 알려 주는 체험 서버라면:

1. `/opt/kait-play/.env` 에 `DEMO=1` 을 넣고 `cd /opt/kait-play && sudo docker compose up -d`
   → 교사 화면의 **비밀번호 바꾸기**가 없어지고(서버에서도 거절), 화면 구석에 "체험 서버" 표시.
   (KAIT-CLASS 쪽은 `/var/www/html/config.php` 에 `'demo' => true,` — 저장소 README 참고)
2. 매일 되돌리기: KAIT-CLASS 의 `kait-class-restore.service`(매일 새벽 4시)가 있는 서버에서, **보여 주고 싶은 상태를 만든 뒤**
   ```bash
   cd ~/kait-class-버전 && sudo bash play/deploy/demo-reset.sh setup
   ```
   → 지금의 game.db 를 `/root/kait-play-snapshot/` 에 뜨고, KAIT-CLASS 를 되돌린 다음 KAIT-PLAY 도 되돌리도록 붙입니다.
   기준을 새로 뜨기: `sudo /usr/local/sbin/kait-play-demo-reset.sh snapshot` · 지금 되돌려 보기: `… restore`

## 3. KAIT-CLASS 를 업데이트한 뒤

따로 할 일이 없습니다. KAIT-CLASS 1.2 부터는 nginx 사이트 설정을 새로 써도 '추가 프로그램 자리'
(`/etc/nginx/kait-class.d/`)의 KAIT-PLAY 연결이 그대로 남습니다.

## 4. 운영 > 설정의 메뉴 링크

KAIT-CLASS 위쪽 메뉴의 **KAIT-PLAY** 링크(새 탭)는 **운영 > 설정 > KAIT-PLAY** 에서 숨길 수 있습니다.
링크는 KAIT-PLAY 가 설치되어 있을 때만(`/var/www/kait-class-data/play.json` 이 있을 때) 보입니다.

## 5. 자주 쓰는 명령

```bash
cd /opt/kait-play
docker compose ps              # 상태
docker compose logs -f         # 기록 보기 (Ctrl + C 로 나가기)
docker compose restart         # 다시 시작 (진행 중인 게임은 사라짐)
docker compose down            # 끄기
```

## 6. 완전히 지우기

```bash
cd /opt/kait-play && sudo docker compose down --rmi all
sudo rm -f /etc/nginx/kait-class.d/kait-play.conf /var/www/kait-class-data/play.json
sudo nginx -t && sudo systemctl reload nginx
sudo rm -rf /opt/kait-play          # 기록 · 문제 은행도 지워집니다. 필요하면 data/ 를 먼저 옮겨 두세요
```

nginx 원본 백업은 `/root/kait-play-backup/` 에 있습니다.

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| `/play/`이 404 | `ls /etc/nginx/kait-class.d/` 에 `kait-play.conf` 가 있는지 → 없으면 `sudo bash play/install.sh` |
| `/play/`이 502 Bad Gateway | 게임 서버가 꺼져 있음 → `docker compose ps`, `docker compose logs --tail 50` |
| 설치 중 "포트를 다른 프로그램이 쓰고 있어요" | `.env`의 `GAME_PORT`를 다른 번호(예: 3200)로 바꾸고 다시 설치 |
| 화면이 안 바뀜 | 브라우저에서 Ctrl + F5 (강력 새로고침) |
| 교사 화면 로그인이 안 됨 | `grep ADMIN_PASSWORD /opt/kait-play/.env`로 비밀번호 확인. 5번 틀리면 1분 동안 막혀요 |
| 지난 기록이 사라짐 | 기록은 `/opt/kait-play/data/game.db`에 있어요. `data` 폴더를 지우지 마세요 |
