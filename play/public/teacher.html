비밀번호 바꾸기

바꾸면 다른 컴퓨터에 열려 있던 교사 화면은 로그아웃돼요. 잊으면 서버에서 docker exec kait-play node scripts/admin-password.js 로 새로 만들 수 있어요.

통계 비밀번호

교사 비밀번호와 따로예요. 바꾸면 다른 컴퓨터에 열려 있던 통계는 닫혀요. 잊으면 서버에서 sudo docker exec kait-play node scripts/stats-password.js 로 새로 만들 수 있어요.
지금은 통계 비밀번호가 없어서 교사 로그인만으로 통계가 열려요. 교사 비밀번호를 혼자 쓰는 서버라면 이대로 충분해요. 교사 비밀번호를 여러 선생님과 함께 쓰는데 통계는 나만 보려면, 서버에서 아래 명령으로 만드세요 (처음 만들기는 화면에서 할 수 없어요 — 교사 비밀번호를 아는 누군가가 먼저 정하지 못하게). sudo docker exec kait-play node scripts/stats-password.js
